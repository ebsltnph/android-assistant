# 随身助手（Android AI 助手）

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Release](https://img.shields.io/github/v/release/ebsltnph/android-assistant)](https://github.com/ebsltnph/android-assistant/releases)

一个跑在你手机上的 AI 助手 App：聊天（含联网搜索）、语音对话、记日记、定时提醒、关注新闻、清晨简报、长期记忆，全部数据保存在手机本地。

接入任意 OpenAI 兼容模型（DeepSeek / 通义 / Kimi / OpenAI / 各类中转站），应用内填 Base URL + API Key 即可使用。

---

## ✨ 功能亮点

### 💬 智能对话

- 流式回复、多轮上下文（长度可调 5-50 轮）、思考过程可展开查看
- **主模型自主调度工具**：提醒、记录、查日记、长期记忆、事件监控、联网搜索、网页全文阅读，全部在对话中自动完成（可连环调用、失败自纠）
- 数学公式（LaTeX）与基础 Markdown 友好渲染；长按可划词复制

### 🎙️ 语音输入（三种方式，设置里自由切换）

- **键盘语音**（默认）：打开面板自动弹键盘，点键盘上的麦克风
- **系统听写**：直接调用系统语音识别（部分机型支持，不支持时自动降级）
- **远程识别**：录音上传到你指派的语音识别模型，说完停顿自动识别并发送——兼容 OpenAI 语音转文字接口（硅基流动 Qwen3-ASR / SenseVoice、whisper 等均可）
- 浮动面板输入框旁有金色 🎙️ 按钮，随时一键语音

### 🔊 语音朗读

- 每条回复旁的喇叭按钮：点击朗读、再点停止、点别的切换
- 对助手说「读出来」，它会自主提炼要点朗读

### 📔 日记与长期记忆

- 聊天里说「记录一下…」自动整理后写入日记，支持多张图片、自定义标签
- **查日记**：说「帮我找找上周记的 XX」「看看标记为工作的日记」，按关键词/标签/天数检索
- 长期记忆：自动抽取重要事实（评分过滤）并注入每次对话，可手动增删改
- 每日小结（可同步系统日历）、指定期间总结、清晨简报

### ⏰ 提醒与资讯

- 说「提醒我明天下午3点开会」自动创建；每天/每周重复、错过自动补排、通知确认机制
- 事件监控：说「关注 XX」定期搜索，重要动态通知你（可自定义规则/域名/周期）
- 清晨简报（今日提醒 + 昨日小结）、免打扰时段

### 👁️ 智能识屏

- 截屏 → 框选区域 → 提取文字 / 翻译 / 总结 / 带图对话，结果自动留存聊天记录
- 四个入口：聊天指令、快捷磁贴、分享图片、悬浮球

### 🫧 悬浮球 + 浮动界面

- 玻璃拟态小球常驻任意应用上层（可拖拽贴边），点击展开浮动面板
- 识屏 / 提醒 / 记录 / 对话四气泡 + 语音输入 + 玻璃输入框，与 App 同一会话
- **图标自定义**：emoji 或相册图片（自动裁圆铺满球体），实时生效

### ✏️ 编辑重发

- 最后一条消息（含带图）旁有 ✏️ 编辑图标：撤回该轮、文字回到输入框，改完重发

### 💾 数据与隐私

- **全部数据只存手机本地**：日记、记忆、对话不上传任何服务器，只调用你自己配置的模型 API
- 一键备份/恢复（ZIP，不含 API Key）；定期自动备份到「下载」目录（卸载不丢）
- 深墨夜景 glassmorphism 主题、悬浮球个性化、使用说明内置

## 📥 安装

### 方式一：下载 APK（推荐）

1. 到 [Releases 页面](https://github.com/ebsltnph/android-assistant/releases) 下载最新版 APK（附件名「随身助手-vX.X.X.apk」）
2. 传到手机（微信/QQ、网盘、数据线均可），点击安装
3. 提示「未知来源」时按提示允许「安装未知应用」

> 荣耀手机提示无法安装：设置 → 安全 → 更多安全设置 → 开启「外部来源应用」。

### 方式二：adb 安装

```bash
# 手机开启开发者选项（设置 → 关于手机 → 连点"版本号"7 次）→ USB 调试
adb install -r app-release.apk
```

### 方式三：源码构建

1. 安装 [Android Studio](https://developer.android.com/studio)（官方免费，自带 JDK 和 SDK）
2. 打开本项目（`File → Open`），等待 Gradle 同步
3. 连接手机（开发者选项 + USB 调试），点 ▶ Run；或终端 `./gradlew assembleRelease` 出正式包

## 🚀 快速上手

### 1. 配置模型（必做，约 1 分钟）

打开 App → 设置 → 模型配置 → 添加提供商：

| 字段 | 说明 | 示例 |
|---|---|---|
| 名称 | 随便起 | DeepSeek |
| Base URL | 不用带 /v1 | `https://api.deepseek.com` |
| API Key | 提供商后台获取 | `sk-...` |
| 模型名 | 按提供商文档 | `deepseek-chat` |

点「测试连接」确认可用 → 打开「设为默认档案」→ 保存。完成后即可使用全部对话功能。

### 2. 开始对话

- 底部导航进「聊天」直接提问；涉及实时信息（新闻/价格/天气）会自动联网搜索
- 自然语言驱动一切：**说**「记录一下今天…」「提醒我明天八点开会」「关注 XX 新闻」「帮我找找上周记的 XX」

### 3. 语音（可选）

- 聊天页：点键盘上的麦克风即可语音输入
- 悬浮球/面板：见上方「语音输入三模式」；想用远程识别，再完成下面一步

### 4. 指派语音识别模型（用远程识别才需要）

1. 模型配置 → 添加（或编辑）一个**支持音频转文字**的提供商（如硅基流动 `https://api.siliconflow.cn`，模型填 `Qwen/Qwen3-ASR-1.7B` 或 `FunAudioLLM/SenseVoiceSmall`），打开「**支持语音识别**」开关
2. 能力指派 → 「语音识别」→ 选择该档案
3. 设置 → 悬浮球 → 语音输入方式选「远程识别」

> 识屏同理：把「识屏（视觉）」指派给支持图片输入的模型（通义 qwen-vl、智谱 GLM-4V 等；DeepSeek 官方 API 不支持图片）。

## ⚙️ 配置速查

| 位置 | 能改什么 |
|---|---|
| 设置 → 模型配置 | 提供商增删改、测试连接、思考深度（五档）、能力指派（对话/识屏/语音识别） |
| 设置 → 悬浮球 | 开关、语音输入方式、图标自定义 |
| 设置 → 搜索（联网） | 默认 keyless 免费模式；可填 Tavily Key（每月 1000 次免费） |
| 设置 → 每日小结 / 清晨简报 / 免打扰 | 开关与时间（精确到分钟） |
| 设置 → 提示词 | 助手系统提示词、识屏提示词直接编辑；其余在「高级设置」 |
| 设置 → 数据备份 | 手动导出/恢复 ZIP；定期自动备份（每天/3 天/周） |
| 设置页最底部 | 版本号（连点 3 次有惊喜） |

## 🛠️ 技术说明

- **技术栈**：Kotlin + Jetpack Compose（Material 3），单模块工程；Retrofit + kotlinx-serialization
- **模型接入**：统一 OpenAI 兼容 API 契约，`ProviderRegistry` 按能力（对话/识屏/语音识别）解析提供商
- **工具调度**：`AssistantTool` 接口 + `ToolRegistry` 注册表，主模型经文本协议 `[调用] {json}` 自主发起，统一回路执行与结果回传
- **持久化**：Room（日记/记忆/提醒/事件/小结）+ DataStore（设置/提示词）+ 加密存储（API Key）
- **后台任务**：WorkManager 周期任务（小结/事件轮询/简报/自动备份）+ AlarmManager 精确闹钟（提醒）
- **公式渲染**：jlatexmath 本地渲染 LaTeX → 位图，无网络依赖
- **隐私**：全部数据保存在手机本地，不上传日记和记忆，只调用你自己配置的模型 API
