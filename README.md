# 随身助手（Android AI 助手）

一个在你手机上的 AI 助手 App，目标功能：

- 🎙️ **语音唤起**：说唤醒词或点悬浮球唤起（分阶段实现）
- 💬 **询问模式**：语音/文字提问，AI 回答（可选语音播报）
- 📔 **日记与长期记忆**：生活/工作分本记录、每日自动整理、记住重要事项
- ⏰ **事件提醒**：定时提醒 + 关注新闻类事件、命中时通知
- 👁️ **智能识屏**：截屏后提取文字 / 翻译 / 详细提问
- 🔌 **自带模型配置**：应用内填 API Key 即可接入 DeepSeek、通义、Kimi、OpenAI 等

## 如何构建运行（新手向）

1. 安装 [Android Studio](https://developer.android.com/studio)（官方免费，自带 JDK 和 Android SDK）
2. 用 Android Studio 打开本项目文件夹（`File → Open`）
3. 等待首次 Gradle 同步完成（会自动下载依赖）
4. 手机开启开发者选项 + USB 调试（设置 → 关于手机 → 连点"版本号"7 次 → 开发者选项 → USB 调试）
5. 连接手机，点 Android Studio 的 ▶ Run 按钮

## 技术说明

- Kotlin + Jetpack Compose，单模块工程
- 模型接入：OpenAI 兼容 API（应用内配置 base URL + API Key），对话与识屏可分别配置不同模型
- 数据全部保存在手机本地（不联网上传你的日记和记忆）
