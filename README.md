# 随身助手（Android AI 助手）

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

一个跑在你手机上的 AI 助手 App：聊天（含联网搜索）、记日记、定时提醒、关注新闻、清晨简报、长期记忆，全部数据保存在手机本地。

## 已实现功能

- 🌌 **深墨夜景主题**：全 App 统一 glassmorphism 风格（深墨底 + 白色玻璃卡片 + 香槟金强调色，与浮动界面一致）
- 🏠 **首页仪表盘**：悬浮球开关 + 清晨简报 / 昨日小结气泡（点击查看）+ 最近提醒（直接显示 4 条）+ 事件监控列表，全部玻璃气泡卡片
- 💬 **AI 聊天**：流式回复（逐字显示）、多轮上下文（长度可在设置里调）、推理模型思考过程分开展示且**可点击展开/收起**、**复制 / 重做**（图标按钮，聊天页与浮动界面均有）
- 🔍 **联网搜索**：问"查一下…""最新消息"时自动联网搜索（Tavily，免注册可用），基于搜索结果回答并注明来源
- 📔 **日记**：单一「日记」本；聊天里说"记录一下…"**自动整理后**入日记（LLM 结合对话与回复总结，能看到主聊天模型的回复）；**支持图片**——聊天发图+「记录」或悬浮球识图+「记录」自动带图，日记页可补图/看大图；写完自动抽取长期记忆
- 🧠 **长期记忆**：LLM 判断重要性（评分 ≥7 才存），记住重要事实（如"以后叫我龙"），每次对话自动注入
- 📅 **每日小结**：每天定时自动汇总最近 24h 日记生成小结推送通知；时间可精确到分钟；历史落库可回看；同步到系统日历；通知点击看完整内容
- 📆 **期间总结**：日记页一键生成**指定时间段**的日记总结（自选起止日期，Material3 日历）；生成后自动保留**最近 5 条**历史可随时回看；总结可一键**复制**到剪贴板或**导出**（系统分享，可存文件/发到其他应用）
- ⏰ **定时提醒**：聊天说"提醒我明天下午3点开会"自动创建；支持每天/每周重复、开机恢复（**错过触发后自动补排下一次，不会失效**）；**触发后自动记入日记**；**通知需点击确认（弹窗手动确认），未确认每 5 分钟重复提醒**；过期提醒自动清理
- 📰 **新闻事件监控**：说"关注 XX 新闻"→ 定期搜索，有重要动态时通知（24h 去重）；**可自定义判断规则和限定来源域名**、调整检查周期（1-168 小时）
- 🌅 **清晨简报**：每天定时推送（默认 7:30 可精确到分钟）：今日提醒 + 昨日小结；**首页随时可看**、通知点击弹窗
- 🌙 **免打扰**：默认 23:00-07:00（可精确到分钟），期间提醒静默、事件监控不打扰
- 👁️ **智能识屏**：聊天说「识屏」/ 点「识屏」磁贴 / 悬浮球选「识图」→ 截屏 → **浮动界面**弹出（提取文字/翻译/总结内容 + 带图对话），结果自动留存到聊天记录
- 🫧 **悬浮球 + 浮动界面**：设置页开启后，一颗玻璃拟态小球常驻任意应用上层（可拖拽贴边）；点击展开**浮动界面**——深墨玻璃拟态 + 动态多色光晕，四个功能气泡（**识图 / 提醒 / 记录 / 对话**）+ 玻璃输入框；与 App 聊天**同一会话**，对话、识屏结果自动留存一份到聊天记录；系统返回手势直接退出回原应用
- 🖼️ **图片分析**：分享图片到助手 / 聊天点 + 上传图片 → 附件栏等待，输入要求后**文字+图片一起发给视觉模型**（如"翻译这张图"）
- ⚙️ **模型配置**：每个提供商可单独**测试连接**、单独设置**思考深度**（OpenAI 通用参数 reasoning_effort，省 token 加速）；对话/识屏/分类能力指派；**聊天上下文长度可调**（5-50 轮）
- 📝 **提示词可编辑**：12 组提示词；常用两组（助手系统提示词 / 识屏提示词）直接编辑，其余 10 组在「高级设置」里编辑或恢复默认
- 🔌 **自带模型配置**：应用内填 base URL + API Key 即可接入 DeepSeek、通义、Kimi、OpenAI 等 OpenAI 兼容接口；对话与识屏可配置不同提供商（识屏需支持图片输入的模型）
- 🖼️ **日记多图**：一条日记可添加多张图片（相册多选、一次最多 9 张）；缩略图点 ✕ 删单张、点图看大图、**一键下载到系统相册**
- 📰 **事件监控详情 + 触发历史**：点事件卡片打开详情窗口（完整配置 + 每次命中记录的时间/标题/内容/原文链接）；命中通知点击直接跳到详情
- 🫙 **秘密功能**（设置页最底部）：自动记录**所有你发出的对话内容**（不含模型回复，只存本机），可导出/清空——为后续制作你的数字分身准备素材
- ➗ **数学公式渲染**：聊天/识屏回复里的 LaTeX 公式（`$…$`、`$$…$$`、`\(…\)`、`\[…\]`，含矩阵/分式/求和）渲染成清晰公式显示；**基础 Markdown** 也支持（加粗/斜体/行内代码/标题/列表）
- 💾 **数据备份与导入**：一键导出全部数据（设置/日记+图片/记忆/提醒/事件/小结/对话历史，**不含 API Key**）到备份文件，可随时恢复（覆盖式 + 自动重启）；**定期自动备份**可选每天/3 天/周，自动存到手机「下载」文件夹（卸载不丢，保留最近 3 份）

## 安装指南（v1.3.1）

### 方式一：直接安装 APK（推荐）

1. 在 GitHub [Releases 页面](https://github.com/ebsltnph/android-assistant/releases) 下载最新版 `app-release.apk`
2. 把 APK 传到手机（微信/QQ 传文件、网盘、数据线复制均可），点击安装
3. 如果提示"未知来源"，按提示允许"安装未知应用"即可
4. 首次使用：打开 App → 设置 → 模型配置 → 添加提供商（填 Base URL + API Key + 模型名，如 DeepSeek `https://api.deepseek.com`）→ 测试连接 → 设为默认

> 荣耀手机提示无法安装时：设置 → 安全 → 更多安全设置 → 开启「外部来源应用」；或用开发者选项 + 数据线 `adb install`（见下方）。

### 方式二：开发者模式安装（adb）

```bash
# 手机开启开发者选项（设置 → 关于手机 → 连点"版本号"7 次）→ USB 调试
adb install -r app-release.apk
```

### 方式三：源码构建

1. 安装 [Android Studio](https://developer.android.com/studio)（官方免费，自带 JDK 和 Android SDK）
2. 用 Android Studio 打开本项目文件夹（`File → Open`），等待 Gradle 同步完成
3. 手机开启开发者选项 + USB 调试，连接手机
4. 点 Android Studio 的 ▶ Run 按钮（调试版）；或终端 `./gradlew assembleRelease` 生成正式版 APK

## 使用说明

1. **设置 → 模型配置**：添加提供商（填名称、Base URL、API Key、模型名）；每个提供商可单独「测试连接」、单独设置思考深度；下方「能力指派」可分别指定对话/识屏/分类模型
2. **设置 → 搜索（联网）**：默认 keyless 免费模式，点「填入 API Key」可填 Tavily Key（每月 1000 次免费，tavily.com 注册）
3. **设置 → 每日小结 / 清晨简报 / 免打扰**：列表直接显示设定时间，点进去改（时间均可精确到分钟）
4. **聊天**：直接打字问问题；说"查一下…"会联网搜索；说"记录一下…"自动整理后写入日记；说"提醒我…"创建提醒；说"关注…"创建事件监控；说"识屏"截屏分析
5. **识屏**：① 聊天说「识屏」→ 授权 → **浮动界面**弹出（提取文字/翻译/总结内容 + 带图对话，结果自动留存聊天记录）；② 下拉通知栏 → 编辑磁贴 → 添加「识屏」→ 在任意 App 里下拉一键识屏；③ 分享图片到助手或聊天点 + 上传 → 附件栏等命令，输入要求后与图片一起发送给视觉模型
6. **悬浮球**：设置 → 悬浮球 → 开启（需悬浮窗权限）或首页顶部开关；在任意应用点小球 → 浮动界面：选「识图」截屏识别，选「提醒」「记录」直接创建，选「对话」或直接输入聊天；系统返回手势退出
7. **日记**：写日记、点「+」给条目补图、点缩略图看大图；点「今日小结」立即生成当天总结（只总结文字内容）；点「期间总结」自选起止日期生成某段时间的总结（可回看最近 5 条、复制、导出）
8. **提醒页**：提醒列表 + 手动添加（重复可选每天/每周，选过去时间自动推到下一次）；事件监控 tab 管理关注事件（周期/规则/域名）
9. **设置 → 识屏模型**：模型配置页底部显示视觉模型状态（DeepSeek 官方 API 不支持图片，需指派通义 qwen-vl / 智谱 GLM-4V / Kimi vision 等）
10. **设置 → 提示词**：常用两组直接编辑；「高级设置」里可编辑其余 10 组或恢复默认

## 技术说明

- Kotlin + Jetpack Compose（Material 3），单模块工程
- 模型接入：统一 OpenAI 兼容 API 契约（Retrofit + kotlinx-serialization），`ProviderRegistry` 按能力解析提供商
- 联网搜索：`SearchClient` 接口 + Tavily 实现（可替换），对话搜索与事件监控共用
- 持久化：Room（日记/记忆/提醒/事件/小结）+ DataStore（设置/提示词）+ 加密存储（API Key）
- 后台任务：WorkManager 周期任务（每日小结/事件轮询/清晨简报/自动备份）+ AlarmManager 精确闹钟（提醒）
- 数学公式渲染：jlatexmath（JitPack `com.github.rikkahub:jlatexmath-android`）本地渲染 LaTeX → 位图，Compose `inlineContent` 内嵌行内公式、块级公式独立一行居中显示
- 数据备份：ZIP（`backup.json` + `images/` + `secret_log/`），SAF 免权限导出/恢复；自动备份走 MediaStore 写公共「下载」目录（API 29+ 免权限）
- 数据全部保存在手机本地（不联网上传你的日记和记忆，只调用你自己配置的模型 API；备份文件由你自己保管）
