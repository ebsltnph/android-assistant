# 随身助手（Android AI 助手）

一个跑在你手机上的 AI 助手 App：聊天、记日记、每日自动总结、长期记忆，全部数据保存在手机本地。

## 已实现功能

- 💬 **AI 聊天**：流式回复（逐字显示）、多轮上下文、推理模型思考过程分开展示
- 📔 **日记**：生活/工作多日记本，在聊天里说"记录一下…"或直接在日记页写；写完自动抽取长期记忆
- 🧠 **长期记忆**：记住重要事实（如"以后叫我龙"），每次对话自动注入，也可手动管理
- 📅 **每日小结**：每天定时自动汇总当天日记生成小结推送通知；时间可在设置页调整（默认 21:00，0-23 点可选）；历史总结落库可回看；同步到**系统日历**（全天事件，每天只留最后一条）
- 🔔 **通知点击**：点每日小结通知 → 打开 App 直接看完整内容
- 🔌 **自带模型配置**：应用内填 base URL + API Key 即可接入 DeepSeek、通义、Kimi、OpenAI 等 OpenAI 兼容接口；对话与识屏可配置不同提供商

## 如何构建运行（新手向）

1. 安装 [Android Studio](https://developer.android.com/studio)（官方免费，自带 JDK 和 Android SDK）
2. 用 Android Studio 打开本项目文件夹（`File → Open`）
3. 等待首次 Gradle 同步完成（会自动下载依赖）
4. 手机开启开发者选项 + USB 调试（设置 → 关于手机 → 连点"版本号"7 次 → 开发者选项 → USB 调试）
5. 连接手机，点 Android Studio 的 ▶ Run 按钮

## 使用说明

1. **设置 → 添加提供商**：填名称、Base URL（如 `https://api.deepseek.com`）、API Key、模型名，保存并设为默认
2. **设置 → 能力指派**：对话、识屏（未来）、意图分类可分别指定模型
3. **聊天**：直接打字问问题；说"记录一下…"会写入当前日记本
4. **日记**：写日记、建日记本；点「今日小结」立即生成当天总结
5. **设置 → 每日小结**：选自动总结时间；授权后同步到系统日历

## 技术说明

- Kotlin + Jetpack Compose（Material 3），单模块工程
- 模型接入：统一 OpenAI 兼容 API 契约（Retrofit + kotlinx-serialization），`ProviderRegistry` 按能力解析提供商
- 持久化：Room（日记/记忆/小结历史）+ DataStore（设置）+ 加密存储（API Key）
- 后台任务：WorkManager 周期任务（每日小结），尊重系统省电策略
- 数据全部保存在手机本地（不联网上传你的日记和记忆，只调用你自己配置的模型 API）
